# Инструкция по локальному запуску «Конструктора квестов»
### Московский Политех

> **Для кого эта инструкция:** данное руководство написано простым и понятным языком специально для пользователей, которые **не имеют опыта в программировании**. Вы сможете легко запустить проект на своем компьютере за пару минут.

---

## Быстрый запуск в 1 клик (для Windows)

1. Убедитесь, что на компьютере установлена бесплатная платформа **Node.js** (см. Шаг 1 ниже).
2. Найдите в папке проекта файл **`start.bat`** (или **`ЗАПУСК_КВЕСТА.bat`**).
3. Дважды кликните по нему левой кнопкой мыши.
4. Скрипт сам проверит окружение, установит зависимости (при первом запуске) и **автоматически откроет сайт в браузере** по адресу **`http://localhost:3000`**.
5. **Готово!** Не закрывайте окно консоли, пока работаете с конструктором. Чтобы остановить сервер — просто закройте окно.

---

## Пошаговая инструкция с нуля

### Шаг 1. Установка платформы Node.js (делается 1 раз)

Для работы сервера требуется бесплатная системная среда **Node.js** (версия LTS):

1. Перейдите на официальный сайт: **[https://nodejs.org](https://nodejs.org)**
2. Нажмите на зеленую кнопку **LTS** (рекомендуется для большинства пользователей).
3. Скачается установщик (файл `.msi`). Запустите его.
4. Нажимайте **«Next» (Далее)**, примите лицензионное соглашение и нажмите **«Install» (Установить)**.
5. Нажмите **«Finish»**.

---

### Шаг 2. Запуск проекта

#### Вариант А. Автозапуск через файл `.bat` (Рекомендуется для Windows)
Просто дважды нажмите на файл:
```text
start.bat
```
*(также работает файл `ЗАПУСК_КВЕСТА.bat`)*

#### Вариант Б. Запуск из терминала (для разработчиков)
В корневой папке проекта выполните команду:
```bash
npm start
```
Сервер запустится и будет доступен по адресу:
```text
http://localhost:3000
```

## Возможности и обновления системы

### 1. Раздел «Сценарии квестов»
Сценарий — это готовая комплексная программа мероприятия, сформированная из готовых сюжетов (этапов):
- **Сборка сценария:** нажмите кнопку **«+ Создать сценарий»**, укажите название, целевую длительность и добавляйте сюжеты.
- **Регулировка этапов:** этапы можно менять местами кнопками **↑** и **↓**, добавлять персональные режиссерские заметки и подсказки для ведущего на каждом этапе.
- **Фильтр «Только из атрибутов»:** позволяет отфильтровать сюжеты и сценарии без использования одноразовых расходных материалов, чтобы провести квест без дополнительных закупок.
- **Автоматический расчет тайминга и реквизита:** система в реальном времени суммирует длительность всех веток, сравнивает с целевым временем и составляет сводную ведомость инвентаря.

### 2. Экспорт плана квеста в PDF
- На карточке любого сценария нажмите кнопку **«Сохранить в PDF»**.
- Откроется оформленный официальный паспорт и план мероприятия Московского Политеха:
  1. Сводная ведомость подготовки реквизита (с разделением на многоразовые атрибуты и расходные материалы, подсчетом количества и графами готовности `[  ]`).
  2. Поэтапный регламент проведения с точным хронометражем, описанием активностей, заданиями и заметками ведущего.
  3. Блок подписи ответственного организатора.
- Нажмите кнопку **«Сохранить в PDF»** в правом верхнем углу — в стандартном системном окне печати выберите «Сохранить как PDF» (Save as PDF).

### 3. Атрибуты и Материалы: минималистичное выделение и фильтры
- **Атрибуты (многоразовый реквизит):** ключи, карты, фонари, замки, реквизитные книги. Выделяются аккуратным синим бейджем.
- **Материалы (расходные):** бумага, маркеры, ленты, краски, стаканчики. Выделяются янтарным бейджем.
- В разделах активностей, сюжетов и сценариев доступны удобные фильтры по типу используемого инвентаря.

### 4. Удобный выбор реквизита в активностях
- При создании и редактировании активности доступен выпадающий список предметов с разделением на группы «Атрибуты» и «Материалы».
- Выбранные предметы наглядно отображаются в виде компактных тегов (chips) с кнопкой быстрого удаления `×`.
- Также доступен аккордеон с чекбоксами для быстрого массового выбора, синхронизированный с выпадающим списком.
